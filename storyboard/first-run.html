First run: from install to one useful answer

A person sets up Claude Code and Codex in one repo, checks that both are on the bus, then watches one agent's answer change the other's code. Every frame is what their terminal shows.

F1Install

One command. The release is not on PyPI, so the README gives the wheel's address.

F2Add a bus to the repo

The bus is a folder inside the repo, kept out of git.

F3Connect both agents

Each setup installs the hooks that join a session to the bus when it starts. Claude Code picks them up in its next session. Codex runs none of them until you trust them.

F4Trust the hooks in Codex

The next time Codex starts, it stops on this screen. Choose Review hooks, check that each of the four commands ends with # agentbus:managed, and trust them. Skip it and Codex never joins the bus, without a word.

F5Check that both are on the bus

Start a Claude Code session and a Codex session in the repo, then ask who is here. This is the step that tells a working setup from a quiet one.

Owner decisionThe tool column cuts claude-code to claude-... (its width cap is 10). The README's ready check reads better if PR B raises the cap to 12. The frames show today's output.

If something is still missing

F6What each session is told when it joins

Each hook adds one note to the agent's context: its bus name and how to read. People never see this; it is why nobody types a command.

F7The first handoff: a question only one agent can answer

The example in examples/first-handoff/ gives Claude the upload limit in its task and gives Codex the tests to write. Codex has drafted a test with a guessed limit. Instead of shipping the guess, it asks.

F8The answer changes the code

This is the moment the README promises. Codex reads Claude's answer and its test changes: the guess goes and the real number comes in, with the message it came from.

F9The example checks itself

A script compares the limit in the code with the one in the tests. It passes only when Codex used Claude's answer.

Owner decisionThe upload limit is a stand-in. Probe P3 picks the real task; the example and these frames follow it.

F10What you saw in watch

The same exchange in watch, with each agent in its own colour. Names from hooks are long, so watch cuts them in narrow columns; the colour is what tells the two apart there.
