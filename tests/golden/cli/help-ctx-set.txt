usage: agentbus ctx set KEY VALUE [--request-id TOKEN]

Set a shared fact and record its history.

ARGUMENTS
  KEY    The fact's name, for example test-command.
  VALUE  The fact's value. Several words are joined; - reads it from stdin.

FLAGS
  -h, --help          Show this help message and exit.
  --request-id TOKEN  Retry safely. Accepted so every write retries the same
                      way; this command already does nothing the second time.

INHERITED FLAGS
  --as NAME  Your agent identity (or AGENTBUS_AGENT)
  --json     Print the result as JSON
  --up N     Use the Nth outer bus (default 0)

EXAMPLES
  # Save a fact
  agentbus --as alice ctx set test-command "npm test"
  # Read the value from a file
  agentbus --as alice ctx set notes - < notes.txt

JSON result: Fact. Retry: safe to repeat.
