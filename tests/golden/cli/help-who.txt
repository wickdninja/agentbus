usage: agentbus who [--limit N]

List the agents that posted, claimed, read with inbox or set a fact, most
recently seen first. One line counts the rest of the roster: names that joined
and never did any of these.

FLAGS
  -h, --help  Show this help message and exit.
  --limit N   At most this many agents (default 50). Use -1 for all.

INHERITED FLAGS
  --as NAME  Your agent identity (or AGENTBUS_AGENT)
  --json     Print the result as JSON
  --up N     Use the Nth outer bus (default 0)

EXAMPLES
  # See who is on the bus
  agentbus who
  # As JSON, five at most
  agentbus --json who --limit 5

JSON result: {"items": [Agent], "has_more": boolean, "next": string or null, "inactive": integer}. Retry: safe to repeat.
