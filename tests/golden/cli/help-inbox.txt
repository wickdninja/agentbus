usage: agentbus inbox [--peek] [--after NEXT] [--limit N]

Unread messages for you, then mark read

FLAGS
  -h, --help    Show this help message and exit.
  --peek        Do not mark read
  --after NEXT  With --peek: continue after the previous page (its next
                value).
  --limit N     At most this many messages (the oldest unread; the rest stay
                unread) (default 20). Use -1 for all.

INHERITED FLAGS
  --as NAME  Your agent identity (or AGENTBUS_AGENT)
  --json     Print the result as JSON
  --up N     Use the Nth outer bus (default 0)

EXAMPLES
  # Read and mark read
  agentbus --as alice inbox
  # Look without marking read
  agentbus --as alice inbox --peek --limit 5

JSON result: {"items": [Message], "has_more": boolean, "next": string or null}. Retry: repeat; dedupe by id.
