usage: agentbus ctx history KEY [--limit N] [--before NEXT]

Show the history of a fact.

ARGUMENTS
  KEY  The fact's name, for example test-command.

FLAGS
  -h, --help     Show this help message and exit.
  --limit N      Maximum facts (get) or values (history); default 50. Use -1
                 for all.
  --before NEXT  Older values than the previous page (its next value).

INHERITED FLAGS
  --as NAME  Your agent identity (or AGENTBUS_AGENT)
  --json     Print the result as JSON
  --up N     Use the Nth outer bus (default 0)

EXAMPLES
  # Every value a fact has had
  agentbus ctx history test-command
  # As JSON
  agentbus --json ctx history test-command

JSON result: {"items": [FactVersion], "has_more": boolean, "next": string or null}. Retry: safe to repeat.
